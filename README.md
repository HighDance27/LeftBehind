## <img width="20" height="20" alt="Star" src="https://github.com/user-attachments/assets/4163e73d-d358-4270-ba4e-0d7f79379626" /> Description 


**Left Behind** is an action-packed 2D top-down shooter developed in Unity. The game focuses on intense, fast-paced combat where players must rely on tactical movement, quick reflexes, and diverse weaponry to survive and dominate the enemies.
<br>
<br>
In this game, you will play as a sole survivor of a special forces,
 abandoned on a remote, hostile island.
 Trapped behind enemy lines, you must fight through terrorist forces, 
 uncover the reason why your unit was left behind, and find a way back to civilization.
 <br>

## <img width="20" height="20" alt="Star" src="https://github.com/user-attachments/assets/4163e73d-d358-4270-ba4e-0d7f79379626" /> Key Highlights

* Battle through hostile territories, scavenge resources, and unravel the mystery of your abandonment in **Campaign** Mode.
* OR team up with up to three other players to face intense combat challenges. Players can choose from four distinct operatives, each featuring different weapons and baseline stats to complement the squad's tactical playstyle. <br>

## <img width="20" height="20" alt="Star" src="https://github.com/user-attachments/assets/4163e73d-d358-4270-ba4e-0d7f79379626" /> Installation

1. Download the latest release `.zip` package for Windows.
2. Extract the downloaded zip file.
3. Run `LeftBehind.exe` to launch the game.


##  <img width="20" height="20" alt="Star" src="https://github.com/user-attachments/assets/4163e73d-d358-4270-ba4e-0d7f79379626" /> Controls

| Action | Key / Input |
| :--- | :--- |
| **Move** | `W` `A` `S` `D` |
| **Aim** | Mouse Cursor |
| **Shoot / Attack** | Left Mouse Button (`LMB`) |
| **Reload** | `R` |
| **Switch Weapon** | `1` - `4` |
| **Dodge** | Spacebar |
| **Pause / Menu** | `Esc` |
| **Scoreboard** | `Tab` |

## <img width="20" height="20" alt="Star" src="https://github.com/user-attachments/assets/4163e73d-d358-4270-ba4e-0d7f79379626" /> Tech Stack

| Category | Technology / Library | Description |
| :--- | :--- | :--- |
| **Engine** | Unity (2D) | Core game engine, 2D physics, animation, and rendering pipeline |
| **Language** | C# | Primary programming language for gameplay logic and systems |
| **Networking** | Photon PUN 2 | Real-time multiplayer synchronization, lobby, and room management |
| **Backend & Services** | PlayFab | User authentication (Sign Up / Login), cloud data, and global leaderboards |
| **UI & Audio** | Unity UI / TextMeshPro | In-game HUD, menu navigation, dynamic typography, and audio management |
| **Version Control** | Git & GitHub | Source code tracking and collaborative development |
